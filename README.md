# VibeAds Studio — Official Website

> **Designing for a Digital World | Turning Ideas Into Global Impact**

Official web platform for **VibeAds Studio**, a modern digital advertising and multimedia production agency. Built with a dark-mode-first aesthetic, responsive layouts, and performance-focused frontend architecture.

### 🚀 Core Services Featured
- **Web Development:** High-speed, responsive corporate sites & landing pages.
- **Brand Identity:** Minimalist logos, vector typography, and stationery design.
- **Social Media Marketing:** Strategic ad designs and performance campaigns (Facebook & TikTok).
- **Video Production & 3D:** High-impact commercial video ads and 3D product renders.

### 🛠️ Tech Stack
- Frontend: HTML5 / Tailwind CSS / React
- Icons: Lucide Icons / Vector SVG
- Deployment: Vercel / GitHub Pages
